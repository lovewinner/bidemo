## 快速预览方式

### 方式 1：直接浏览器双击打开
直接使用任何现代浏览器（Chrome、Edge、Safari、Firefox）双击打开本目录下的：
```bash
/home/ubuntu/codes/tmp/index.html
```

### 方式 2：使用本地 HTTP 服务启动预览
在终端执行以下命令：
```bash
cd /home/ubuntu/codes/tmp
python3 -m http.server 8080
```
然后在浏览器中访问：`http://localhost:8080`

## 关键交互功能亮点

1. **红黄绿灯与一键督办（闭环管理）**：
   - 首页右上角通知铃铛及督办台集成高优先级告警（如计算机学院就业率偏低、AI研究院设备预算偏慢）。
   - 点击任一告警项的**“一键批示督办”**，即可呼出《校领导重点督办批示单》弹窗，支持录入批示意见并模拟正式派单。
2. **二级学院下钻穿透（Drill-down）**：
   - 在综合态势看板中的“二级学院办学绩效积分榜”中，点击任意学院（例如：**材料科学与工程学院**、**人工智能与计算机学院**），即可弹出**学院五维全息画像弹窗**，查看其专属的学科评估预测雷达和在研重大专项。
3. **顶端警情滚动快报（Ticker）**：
   - 顶部跑马灯滚动展示跨部门实时异动，支持点击直接联动督办派单。
4. **侧边栏预警台账抽屉**：
   - 点击右上角红点铃铛，右侧滑出全校多部门运行异动总台账。
